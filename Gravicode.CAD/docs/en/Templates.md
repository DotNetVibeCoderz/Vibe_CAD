# Project templates

> 🇮🇩 [Baca dalam Bahasa Indonesia](../id/Templates.md)

```bash
dotnet new install Gravicode.CAD.Templates
```

| Template | Command | Contents |
|---|---|---|
| Console | `dotnet new cad-console -n MyPart` | parametric bracket → STEP, STL, GLB, PDF drawing, PNG |
| Web API | `dotnet new cad-webapi -n CadApi` | `GET /parts/plate.step?w=150`, `POST /convert/{ext}`, `POST /ai/generate`, `GET /formats` |
| Blazor | `dotnet new cad-blazor -n CadWeb` | `<CadViewer>` with live sliders for a flange |
| WPF | `dotnet new cad-wpf -n CadWpf` | `CadViewport` + open dialog (`Model = CadModel.Load(...)`) |
| WinForms | `dotnet new cad-winforms -n CadForms` | `viewport.Load("engine.step")` |
| Avalonia | `dotnet new cad-avalonia -n CadDesk` | ThreeNet GPU viewer, cross-platform |
| MAUI | `dotnet new cad-maui -n CadMobile` | gear preview with a teeth slider (Android, Windows) |

Every template references the Gravicode.CAD NuGet packages of the same version and builds with `dotnet run`. The `cad-maui` template needs the MAUI workload (`dotnet workload install maui`).

Uninstall: `dotnet new uninstall Gravicode.CAD.Templates`.

Template sources live in `templates/Gravicode.CAD.Templates/content` and are generated by `gen_templates.py`.
